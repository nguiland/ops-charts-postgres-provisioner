Postgres Provisioner has been installed successfully.

The provisioner runs as a Kubernetes controller and does not expose an application URL or require a Kubernetes Service or Ingress.

**Check the deployment:**

```bash
kubectl get deployment -n {{ .Release.Namespace }} {{ include "postgres-provisioner.fullname" . }}
```

**Check the provisioner pods:**

```bash
kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}
```

**View the provisioner logs:**

```bash
kubectl logs -n {{ .Release.Namespace }} deployment/{{ include "postgres-provisioner.fullname" . }}
```

**Check the PostgresInstance resources:**

```bash
kubectl get postgresinstances --all-namespaces
```

To provision a database, create a PostgresInstance resource and label the database Secrets that should be managed by this provisioner.
